## 🎮 Что это

**DEVIANT TOOL** — программа для слабых и средних ПК, которые играют в **GTA 5** на **Majestic RP**.

Она не ставит моды и не лезет в античит. Она приводит в порядок **память, Windows, оверлеи и графику GTA**, чтобы меньше было чёрных дыр, фризов и просадок FPS.

Подходит, если:

- 8 ГБ видеокарты и 16 ГБ ОЗУ уже «впритык»
- после рейда пропадают текстуры
- висят Broadcast, Xbox Game Bar, Epic Overlay
- не хотите закрывать Discord ради игры

Исходников в этом репозитории нет: здесь только готовые сборки. Качайте exe **только из Releases**. Другие ссылки — не наши.

## ✨ Плюсы

- **Discord, GTA и лаунчер Majestic не закрывает.** Голос и игра остаются.
- **Без ASI и без запрещённых ключей** вроде `-textureQuality`, `-memrestrict`, `-norestrictions`.
- **Три пресета** под задачу: Дыры, Баланс, FPS. Не нужно гадать ползунки с нуля.
- **Советы именно для вашего ПК** — админ, ASI в папке, Radmin, маленькая подкачка. Не общий список на всех.
- **Каждый пункт с подсказкой i** — что будет, если включить, и что если выключить.
- **Откат графики** из бэкапа, который программа делает сама.
- **Перед рейдом** — короткий проход: память и оверлеи, без правки XML.
- **Обновления только с этого GitHub**, с проверкой SHA256. Чужой файл не поставится.
- Один exe, без установки. Настройки лежат у вас в `%APPDATA%\DEVIANT-TOOL`.

## ⚡ Что делает

### 💻 Память

- сбрасывает «запас» ОЗУ у фоновых программ, не убивая Discord и GTA
- показывает свободную оперативку и видеопамять
- может поставить файл подкачки 24 ГБ (по желанию, нужны права администратора)
- чистит ваш TEMP и по желанию кэш шейдеров NVIDIA

### 🖼️ Картинка GTA

- пишет графику в `settings.xml`: текстуры Normal, без MSAA и ультра-теней
- пишет официальный `commandline.txt` с лимитом видеопамяти (`-availablevidmem`)
- оставляет Windows и Discord запас VRAM (резерв, обычно 2048 МБ на 8 ГБ карте)
- после смены графики нужен **релог** в Majestic — иначе XML не применится

**Пресеты**

| Пресет | Для чего |
|---|---|
| **Дыры** | меньше чёрных пустот, больше запас VRAM |
| **Баланс** | обычный вечер / день на среднем ПК |
| **FPS** | максимум кадров, картинка проще |

### 🖥️ Оверлеи и запись экрана

- выключает NVIDIA Broadcast и снимает его с автозагрузки
- закрывает Epic Overlay, NVIDIA Overlay, Xbox Game Bar
- глушит оверлей Discord (сам Discord не закрывает)
- выключает Share / Ansel / Instant Replay
- Game Mode, выключение Game DVR, высокая производительность GPU
- высокий приоритет `GTA5.exe`

### ⚙️ Windows (по желанию)

На странице **Система** — то, что не всем нужно. По умолчанию часть выключена.

- схема питания «максимум»
- меньше анимаций и прозрачности Windows
- мышь 1:1 без ускорения
- уведомления и Game Bar не всплывают в бою
- фон Edge, раздача обновлений, индекс папки GTA
- автозагрузка Broadcast / Epic / Spotify / Teams — Discord не трогает
- по отдельной галочке: браузеры, OneDrive, SysMain, Winsock

Каждый пункт можно включить или выключить. «Оптимизировать» гоняет только то, что включено.

## 🔄 Что обновляет программа

Когда вы жмёте **Оптимизировать**, DEVIANT меняет только то, что вы включили:

1. **Игру** — `settings.xml` и `commandline.txt` в папке, где лежит `GTA5.exe`
2. **Память** — рабочие наборы процессов, по желанию подкачка
3. **Оверлеи** — Broadcast, Epic, NVIDIA, Xbox, оверлей Discord
4. **Windows** — Game Mode, питание, уведомления, мышь, автозагрузка
5. **Саму себя** — новая версия качается только с этого репозитория

Не обновляет драйвер NVIDIA, не ставит Visual C++ и DirectX, не качает ASI. Если чего-то не хватает — напишет в журнале и даст ссылку, что поставить самому.

Автообновление DEVIANT:

- спрашивает в своём тёмном окне, не в системном Windows
- качает только `loufi12/DEVIANT-UPDATES`
- сверяет SHA256 файла с README и релизом
- если хеш не совпал — **не ставит**

Старые сборки 1.1.0–1.1.2 с GitHub сняты. Актуальна только последняя версия.

## 🚀 Как пользоваться

1. Скачайте exe из [последнего релиза](https://github.com/loufi12/DEVIANT-UPDATES/releases/latest).
2. Проверьте на [VirusTotal](https://www.virustotal.com/gui/file/099e18a89a63afc8178301ce882371175ce738301218dddadf64ea43e303e9c2).

4. Найдите папку с `GTA5.exe`, выберите пресет или нажмите «Оптимизировать».
5. Если меняли графику на уже запущенной GTA — выйдите из персонажа и зайдите снова.
